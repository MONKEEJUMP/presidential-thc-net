# Presidential THC

`presidentialthc.net` is a code-native, 29-page reference publication about the chemistry and craft of infused cannabis. It uses Next.js, TypeScript, Tailwind CSS, local WebP packaging art, static content, and no CMS.

## Run

```powershell
npm install
npm run dev
```

The production gate is:

```powershell
npm run build
```

Canonical production host: `https://presidentialthc.net`.

The main Presidential site is a separate property and repository. Do not copy its editorial copy or modify its source tree from this project.
